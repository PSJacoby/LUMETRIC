# Welcome to LUMETRIC

LUMETRIC is a powerful, flexible acquisition and live-data visualization system for fluorescence microscopy, designed to make both simple and advanced imaging experiments accessible to everyone. Whether you want to quickly visualize live data from a single-channel experiment, set up complex multi-channel acquisition regimes with precise timing, or perform photoswitching experiments, LUMETRIC provides an intuitive interface and robust automation.

## What can LUMETRIC do?

- **Live Data Plotting and Live FRET Ratio**

    Instantly visualize intensity or intensity ratios (OptoSplit) from regions of interest (ROI) in real time. Perfect for classical fluorescence/FRET experiments — no additional hardware required.
