# Quick - start LUMETRIC

**Process in snapshots for the first steps below.**

**Goal:** This section gives you an example of a simple FRET experiment with live plotting. The provided pictures can only serve as an orientation what to look for. Precise naming of configurations, presets and similar depend on your system setup.

1. Open your MicroManager Instance.
2. Make sure your config file is correct.
3. Set your basic Presets and Settings. Focus your cells.
4. Open LUMETRIC via your Quick Access Button.
5. Configure the sequence table (one or multiple rows). Select your 'Save' - folder and Name your experiment.
6. Go to Tab 3 – Data Visualization
      1. Choose your mode (spatial/ temporal)
      2. Configure graphs: each Intensity or Ratio, which Row, which window
      3. (Optional) Enable Background correction
      4. Click OK – Start Acquisition
7. Draw ROIs in Acquisition Window
8. Measure
9. Quit and check export
