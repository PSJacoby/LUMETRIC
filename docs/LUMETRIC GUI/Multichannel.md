# Quick - start LUMETRIC

**Goal:** Run a simple single-channel experiment with live plotting

1. Open LUMETRIC > make sure your config file is all set. Deselect LUMETRIC *lite*
2. Configure the sequence table (one or multiple rows)
3. Select 'Save' - folder
4. Go to Tab 3 – Data Visualization
      1. Choose your mode (spatial/ temporal)
      2. Configure graphs: each Intensity or Ratio
      3. (Optional) Enable Background correction
      4. Click OK – Start Acquisition
5. Draw ROIs in Acquisition Window
6. Measure
7. Quit and check export
