# Quick - start LUMETRIC *lite*

**Goal:** Run a simple single-channel experiment with live plotting

1. Open LUMETRIC > select 'LUMETRIC *Lite*'
2. Ensure camera + illumination presets are according to your plans (live view test)
3. Go to Tab 2 – Acquisition Settings and check the tick at 'LUMETRIC Lite'
4. Configure Row 1 only:
      1. Exposure [ms]
      2. Frame Interval [ms] (> exposure)
      3. Select Save folder
5. Go to Tab 3 – Data Visualization
      1. Choose your mode (spatial/ temporal)
      2. Configure graphs: each Intensity or Ratio (use All Rows)
      3. (Optional) Enable Background correction
      4. Click OK – Start Acquisition
6. Draw ROIs in Acquisition Window
7. Measure
8. Quit and check export
